# NookNest 🏡

🌐 Live Site: https://nooknest.vercel.app/

---

## 📌 Description

NookNest is a modern premium study room and workspace booking platform built with Next.js. It provides users with a clean, fast, and responsive experience to explore, filter, and book study rooms with ease. The platform is designed with a focus on productivity, comfort, and premium UI/UX.

---

## 🚀 Features

- 🏠 Browse premium study/work rooms
- 🔍 Advanced search and filtering system
- 💰 Price range filtering (min/max)
- 🪑 Amenities-based filtering
- 📱 Fully responsive design (mobile + desktop)
- ⚡ Fast performance with Next.js App Router
- 🌙 Dark/Light mode support
- 🧭 Clean and modern UI/UX
- 📄 Dynamic room details pages
- 🔄 Loading spinner & smooth UI transitions
